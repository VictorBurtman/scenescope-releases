## English product description

### Summary

Inspect 3D scenes, animation and simulation caches in a Windows desktop viewer.
Free download, with an optional contribution to development.

### Description

SceneScope helps you explore a scene's hierarchy, properties and animation,
and understand its data through viewport diagnostics.

Preview supported USD, Alembic, FBX, OBJ, XMesh, Houdini BGEO, OpenVDB and
observed tyCache layouts, alongside MaterialX look development. Examine Normal,
Velocity and Object ID views, color eligible geometry from attributes and inspect
supported volume fields. Available features depend on the format and source data.

## Description française

### Résumé

Inspectez vos scènes 3D, animations et caches de simulation dans une application
Windows. Téléchargement gratuit, avec une contribution facultative au développement.

### Description

SceneScope permet d'explorer la hiérarchie, les propriétés et l'animation d'une
scène, puis de mieux comprendre ses données grâce aux visualisations du viewport.

Prévisualisez les formats pris en charge : USD, Alembic, FBX, OBJ, XMesh,
Houdini BGEO, OpenVDB et certains exports tyCache, avec des outils de look

colorez les géométries compatibles à partir de leurs attributs et inspectez les
champs de volume pris en charge. Les fonctions disponibles dépendent du format
et des données présentes dans le fichier.

d'installation. Les téléchargements GitHub sont publics et gratuits. Vous pouvez
